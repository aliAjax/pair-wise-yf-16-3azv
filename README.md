# hxyfront-62004 滑雪板调校维护台

面向滑雪板调校店的装备维护前端：技师登记雪板品牌、长度、板型、刃角、蜡型与客户偏好，
标记底板伤并管控完工，维护客户偏好档案。

## 业务规则

- **底板伤三态**：待修补 / 已修补 / 无需处理，伤点需记录位置与备注。
- **完工闸门**：工单上只要还有「待修补」伤点，点完工不会改变状态——工单保持「维修中」，
  界面列出所有阻挡位置；全部标记为「已修补」或「无需处理」后才能完工，才会出现在「已完工」筛选中。
- **偏好快照**：每张工单保存建单时的客户偏好与板况参数快照。在客户档案中修改偏好
  只影响**之后新建**的工单，旧工单的偏好和刃角、蜡型等参数一律不变（卡片上标「旧偏好已保留」）。
- **本地持久化**：数据存于浏览器 `localStorage`（键 `ski-tuning-console:v1`），重开页面仍在。

## 代码分层

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 模型 | `src/model/` | 数据类型、固定选项（`types.ts`）、初始数据（`seed.ts`）、本机存储（`storage.ts`） |
| 规则 | `src/rules/` | 完工闸门、阻挡判定、偏好快照与状态迁移（`orderRules.ts`、`customerRules.ts`、`reducer.ts`、`actions.ts`），均为纯函数 |
| 界面 | `src/ui/` + `src/App.tsx` | 工单卡片、底板伤标记区、筛选、新建表单、客户档案，只派发动作不直接改数据 |

`src/state/store.tsx` 是把规则层接到 React 的薄 store（useReducer + 持久化 effect）。
