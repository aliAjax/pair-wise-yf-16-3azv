# hxyfront-62004 滑雪板调校维护台

面向滑雪板调校店的装备维护前端：技师登记品牌、长度、板型、刃角、蜡型和客户偏好，
管理底板伤修补进度，控制工单完工。

## 业务规则

- **完工门槛**：每张工单的底板伤标记为「待修补 / 已修补 / 无需处理」。
  存在「待修补」时点完工，工单保持「维修中」并列出阻挡位置；
  全部改成「已修补」或「无需处理」后，再次完工才进入「已完工」，
  因此筛「已完工」只会看到真正处理清楚的工单。
- **偏好快照**：客户偏好的改动只更新客户档案、只影响之后新建的工单；
  旧工单保留建单时的偏好文本和刃角 / 蜡型参数（完工时再冻结一次参数快照）。
- **本机持久化**：数据存浏览器 `localStorage`（key：`ski-workshop-state-v1`），
  重开浏览器仍在；侧栏可一键恢复演示数据。

## 分层结构（模型 / 规则 / 界面分开）

```
src/
├── types.ts                  模型：数据类型（工单、底板伤、客户…）
├── rules.ts                  规则：完工阻挡判定、板型参数表、偏好推荐（纯函数）
├── model/
│   └── storage.ts            模型：localStorage 读写与种子数据
├── hooks/
│   └── useWorkshop.ts        状态：所有操作经 rules 判定后落盘
├── components/               界面：表单、工单卡片、侧栏筛选
│   ├── NewOrderForm.tsx
│   ├── OrderCard.tsx
│   └── Sidebar.tsx
└── App.tsx                   组合：指标、筛选、工单列表
```

规则层是不依赖 React 的纯函数，可直接单测；存储层只有 `loadState/saveState`，
界面组件不直接碰 localStorage。
